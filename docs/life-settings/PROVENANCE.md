# 来源与许可

本项目是 SurfCore 的独立衍生开发，保留原作者的 QQ 桥接、B站工具与调度、目的机制、记忆、身份、预算和 DSH 插件基础设施。

- 实际复用来源：https://github.com/Mieksido/surfcore
- 克隆基线 commit：8c55cda75b7374182a16428372ad42e451190de8
- 基线 package 版本：0.6.3；本地衍生功能版本：0.7.0。
- 本轮没有找到已有本地 SurfCore 检出，因此独立克隆；没有覆盖其他工作区。
- 原 LICENSE 字节保持不变，包含 MIT 版权声明及上游第三方说明。原作者已有代码不作为本轮独立原创宣传。
- 新增工作的重点是有界参数管理、实际消费者接线、采用证据、冲突/耦合/回滚与可演示验收。

SnowLuma、SDK/MCP、DSH 及其他依赖各有原始许可。MIT 不替代第三方许可。本轮未复制或打包第三方运行时、二进制或 node_modules；安装依赖仅存在本地且由 Git 忽略。原 postinstall 机械修补仅对本地已安装的 SDK 副本补相对导入扩展名，未进入本仓库，未自动安装或启动 SnowLuma。

本轮仅本地开发、测试和本地提交；没有创建远程仓库、公开 PR/Issue、上传计划、推送代码或生成包含第三方依赖的发布包。拟议远程地址不是已经发布的证据。以后公开前应再次核对依赖许可及无私人数据。
