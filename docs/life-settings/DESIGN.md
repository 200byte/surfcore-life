# 自主生活参数：设计与边界

本目录记录 2026-10-27 独立 SurfCore 衍生开发。目标是让 Agent 在已有授权范围内理解、选择和检验生活参数，不为她预写新的人格、心理体验或永久偏好。原 QQ/B站、目的、记忆、身份与预算实现继续承担业务行为。

## 问题、根因、影响与修法

| 项目 | 调查结论 / 处理方式 |
| --- | --- |
| 现象 | 人类可在多个设置页保存参数，Agent 却难以判断参数由谁读取、是否被覆盖以及何时真正生效。 |
| 根因 | `config.json`、`bili.config.json`、统一配置、每会话 wakeConfig、旧 `whale-night.config.json` 与调度状态分属不同消费者；QQ 部分配置只在启动读入，B站则存在 CLI 与插件两条路径。 |
| 影响面 | 保存成功可能不改变已排定计时器；修改一个间隔可能被每日上限、时窗、概率或预算压住；并发读改写可能丢失选择；读取配置不能证明模型请求或调度器采用了该值。 |
| 修法 | 加入严格白名单的生活参数目录、单一事务覆盖文件、意图预览与显式提交、消费者独立上报的运行证据、版本冲突检查、可追溯历史与有界回滚。 |
| 验证 | 隔离目录中的真实读写与消费者链：预览不写入、提交版本变化、进程读到新版本、旧计时器按约定更新、遗留覆盖无法吞掉新选择、错误与并发不损坏配置、回滚恢复先前覆盖；平台发送与真实模型请求另外验收。 |

## 路线比较

| 路线 | 收益 | 成本 | 风险 | 回滚 |
| --- | --- | --- | --- | --- |
| 重写配置与全部调度引擎 | 所有设置可以统一存储 | 必须迁移 QQ、B站、插件、CLI、记忆、账号与设置页，成本高 | 易损失成熟能力、迁移用户数据，影响原有安全闸 | 需回退数据格式、多个消费者与业务流程，难 |
| 受限事务覆盖层（本轮采用） | 用较小改动获得 Agent 原生发现、解释、预览、选择、验证与回滚 | 给明确参数增加消费者接线与证据；其余保持只读或审批 | 要认真处理优先级、遗留覆盖、计时器捕获旧值和证据过期 | 撤销指定覆盖即可回到原基础配置；历史保留，无须覆盖整份用户配置 |

选择第二条路线的依据是工程收益与影响面。它不是允许 Agent 编辑任意 JSON；未登记字段不可透传，基础配置中的凭据与账号资料不进入事务快照。

## 权威配置和运行证据

`<DSH_HOME>/surfcore/life-settings.json` 是本轮受管覆盖与变更历史的事务来源。基础配置文件保留原功能，只读提取正式目录允许的字段。一个计划必须绑定当前版本和相关基础值；执行时重新校验，避免把过期预览应用到已变化的环境。

消费者在真正采用覆盖后，发布自己实例的快照。查询方不以“重新读了一遍配置”代替消费者证据。证据至少需要来源、实例、观察时间、配置版本及所采用值；过期、不同实例、旧版本或缺少观察时，明确显示待验证、失配或未知。进程内采用值是调度接线证据，不等于已发生 QQ 发言、B站浏览或线上缓存命中。

基础配置变化与普通参数覆盖的优先级必须明确：受管覆盖在消费者使用前应用；遗留 `whale-night.config.json` 不能在之后无提示地覆盖受管选择。未受管字段保持原优先级。回滚只恢复事务中的先前覆盖，不回写整个基础文件，不重置预算用量、已发生次数或平台凭据。

## Agent 工具契约

工具接口分别承担状态、目录、解释、预览、执行、验证、历史、回滚和观察。正式工具名及参数以项目运行时注册的 schema 为准。

1. 状态仅返回可溯源事实、当前消费者和待验证变更；未接通的平台不伪装在线。
2. 目录和解释给出稳定 ID、中文说明、默认值、保存值、可证明的实际值、范围、成本、依赖、权限、生效与恢复方式。
3. 预览接受显式参数或已登记的生活意图，列出全部关联修改、约束和验证方式。关键词搜索只帮助发现，不执行修改。
4. 执行需要 Agent 选择预览计划并给出理由；版本或来源变化时拒绝过期计划。不能通过额外 JSON 键绕过字段目录。
5. 验证读取消费者快照。没有证据时返回“已保存，尚未验证生效”。
6. 历史区分修改者、原由、前后值、提交事实与观察事实；Agent 自述原因按自述记录。
7. 回滚使用同一校验和事务路径。并发变化时先拒绝旧回滚，保留现场，不强制覆盖其他修改。
8. 观察记录后来发生的可见事实和 Agent 的保留/撤销选择；不额外调用模型，不推断她的心理。

工具提供便利，不代替主体做选择。参数影响“机会、提示和节奏”，不能保证她一定发言、一定看某视频或形成某种兴趣。

## 权限

普通生活偏好可以在明确范围内自主调整。模型/思考档位和硬额度变化只进入操作员处理的审批请求；Agent 不拥有审批自己请求的接口。未实现操作员执行链的项目必须保持待审批，不声称已生效。

以下不经普通参数接口修改：凭据、cookie、账号身份、QQ 白名单/黑名单、安全模式、权限 preset、外部资源授权、通知命令/URL、代码路径、预算硬上限、鱼群保护硬闸、记忆原文/遗忘/跨平台隐私开关。目录中可只读解释其约束，但不暴露秘密或私人正文。

原 B站会话已有的广泛 shell 权限属于上游安全边界；新增参数工具的有界权限不自动把同一进程的所有 shell/文件能力变成操作系统隔离。真实部署仍须由操作员确定会话权限及文件 ACL，不能宣传此覆盖层为不可篡改身份保险箱。

## 时钟、状态板与费用

每次主要唤醒在当前 DSH 消息末端携带精简事实：时间/时区、唤醒原因、当前消费者/修订、节奏与可见预算、待验证变更。完整目录按需查。动态状态不重写静态 system/Core，不把人类默认兴趣标成 Agent 自选兴趣，不反复注入整张参数表。

状态与查询不发起额外模型请求。离线测试可以验证 prompt 队列中静态前缀与追加状态的位置；无法取得官方 Adapter wire 或平台 usage 时，缓存命中率、实际 reasoning 及官方扣款保持未知。上游 token 账是 session events 和价格表计算口径，不能替代 API 平台实际入账金额。

## 本轮验证边界

开发只使用独立源码与隔离 fixture，不修改云宝 / deepseek-harness-digital-life 的源码、真实数据或运行状态。不开真实 QQ/B站发送，不唤醒真实生命，不启动持续付费循环。最终通过结果、可录屏入口、实际参数目录和剩余验收事项以本目录交付报告及测试输出为准；本设计文档本身不是通过证明。
